# 1. Straightforward Prompt

## Description

A Straightforward Prompt gives the AI a direct instruction without additional context or constraints.

### Example Prompt

> Suggest the top five tourist places to visit in Ooty.

### Sample Output

- Botanical Garden
- Ooty Lake
- Doddabetta Peak
- Rose Garden
- Pykara Falls

### Evaluation

- Very fast response
- Easy to understand
- Suitable for simple queries

---

# 2. Tabular Format Prompting

## Description

Tabular prompting instructs the AI to organize information into rows and columns for easy comparison.

### Example Prompt

> Create a table showing popular tourist places in Ooty, entry fee, best visiting time, and major attraction.

### Sample Output

| Tourist Place | Entry Fee | Best Time | Attraction |
|---------------|-----------|-----------|------------|
| Botanical Garden | ₹50 | April–June | Flower Collection |
| Ooty Lake | ₹20 | All Year | Boating |
| Doddabetta Peak | ₹10 | Morning | Scenic View |
| Rose Garden | ₹40 | Summer | Rose Varieties |

### Evaluation

- Excellent readability
- Easy comparison
- Best for reports

---

# 3. Missing Word Prompting

## Description

Missing Word Prompting asks the AI to complete blanks using contextual understanding.

### Example Prompt

> Ooty is famous for its ________, tea plantations, and cool ________.

### Sample Output

> Ooty is famous for its **hill stations**, tea plantations, and cool **climate**.

### Evaluation

- Accurate completion
- Good contextual understanding
- Useful for educational exercises

---

# 4. Preceding Question Prompting

## Description

The AI asks a clarifying question before providing the final answer.

### Example Prompt

> Recommend a travel plan, but first ask me my budget and number of travel days.

### Sample Output

**AI:** What is your travel budget and how many days are you planning to stay?

**User:** ₹10,000 for 3 days.

**AI:** Based on your budget, I recommend visiting Ooty Lake, Botanical Garden, Doddabetta Peak, and staying in a budget hotel near the city center.

### Evaluation

- Personalized response
- Better recommendations
- More interactive

# Comparison of Prompt Types

| Prompt Type | Best Use | Advantage | Limitation |
|--------------|----------|-----------|------------|
| Straightforward | Simple queries | Fast | Less detailed |
| Tabular | Comparisons | Highly organized | Not needed for short answers |
| Missing Word | Learning | Improves contextual understanding | Limited flexibility |
| Preceding Question | Personalized recommendations | More accurate | Takes more interaction |
